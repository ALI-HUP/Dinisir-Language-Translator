# 🦖 مترجم دینیسیر | Denisir Translator

یک اپلیکیشن وب فانتزی و مدرن برای تبدیل متن‌های فارسی به زبان «دیناسور بدون فک» با پشتیبانی از هوش مصنوعی! 🚀

A fun, modern web application designed to translate Persian text into the "Jawless Dinosaur" dialect, powered by AI! 🚀

---

## نسخه فارسی

### 📌 درباره پروژه

مترجم دینیسیر یک ابزار آنلاین طنزآمیز و تعاملی است که متن‌های فارسی (زبان آدمیزاد) را گرفته و آن‌ها را به آواها و لحن بانمک دایناسوری تبدیل می‌کند. این پروژه با رابط کاربری جذاب، تم نئونی ژوراسیک و انیمیشن‌های روان طراحی شده است.

### ✨ ویژگی‌های کلیدی

- 🤖 **پشتیبانی از هوش مصنوعی:** استفاده از مدل‌های Gemini برای تولید ترجمه‌های دایناسوری.
- 🎨 **رابط کاربری مدرن و واکنش‌گرا (Responsive):** طراحی بهینه شده برای موبایل، تبلت و دسکتاپ.
- 🌌 **بک‌گراند زنده و پویا:** دارای افکت نورانی و تعاملی StarBurst با کانوای ۲ بعدی.
- 🛑 **هشدار هوشمند زبان انگلیسی:** شناسایی حروف انگلیسی و نمایش مودال طنزآمیز با افکت Backdrop Blur.
- 📋 **تاریخچه و متون پیشنهادی:** قابلیت انتخاب سریع جملات پیشنهادی و مشاهده تاریخچه ترجمه‌ها.

### 🛠 تکنولوژی‌های استفاده‌شده

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide React
- **Animations:** HTML5 Canvas (StarBurst Effect) & Tailwind CSS
- **AI Integration:** Google Gemini API
- **Deployment Ready:** Vercel

## 🇬🇧 English Version

### 📌 About The Project

Denisir Translator is a humorous and interactive web application that converts standard Persian text into a fun "Jawless Dinosaur" dialect. Built with a sleek Jurassic neon aesthetic, it features smooth animations and intelligent language detection.

### ✨ Key Features

- 🤖 **AI-Powered:** Utilizes Gemini API to generate contextual dinosaur translations.
- 🎨 **Fully Responsive UI:** Optimized layout for seamless use across Mobile, Tablet, and Desktop.
- 🌌 **Dynamic Canvas Background:** Integrated interactive `StarBurst` radial particle system.
- 🛑 **Smart English Detection:** Displays a custom humorous warning modal upon detecting English characters.
- 📋 **Presets & History:** Includes one-click suggested prompts and recent translation history.

### 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Graphics & Animation:** HTML5 Canvas & Native Tailwind CSS Animations
- **AI API:** Google Gemini API

### 🚀 راه اندازی پروژه | Quick Start

```bash
# کلون کردن مخزن | Clone the repository

# ورود به پوشه پروژه | Enter directory
cd dino-translator

# نصب پکیج‌ها | Install dependencies
npm install

# اجرای برنامه | Run development server
npm run dev
```
